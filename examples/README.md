# MEGFlow examples

Start with the [runnable shell examples](run_scripts/) for portable Docker and
host-Nextflow launch commands. The [MEGFlow examples](megflow/) contain
notebooks and configuration fragments, while [OPM conversion examples](opm_conversion/)
cover standard OPM data conversion.

For the complete workflow and configuration reference, see the repository
[README](../README.md) and [documentation](../docs/source/quickstart/quick_guide.rst).
